User Guide

This guide will document how to use FreshApples as product features become available.

Admin review moderation

Open Review moderation in the Admin navigation. The queue includes pending, flagged, cleared, hidden and author-deleted reviews. Choose an assessment/state filter or a Movie ID, then Apply filters. Each row's Reviews for this Movie link selects that Movie. All reviews clears the filters and returns to the first page.

Open Review by [author] to read the current text alongside the labelled automatic assessment. An older assessment is marked historical and does not describe the current text. Read its limitations; automatic screening can be wrong. Every status is written in text.

Enter a reason of 10–1,000 characters and choose Approve review, Hide review, or Restore review when available. The confirmation names the author and Movie and explains the effect. Cancel or Escape closes it without saving. Successful decisions are announced on the page.

Approval does not undo an author deletion or an Admin hide. Restore removes only the Admin hide: pending or flagged text remains unpublished, and archived Movies stay non-public. Pending work resumes automatically later; there is no manual AI-generation control. These actions do not add strikes.

If someone changed the review, your reason is kept. Choose Load latest version, read the new text, and confirm a fresh decision. Loading the latest version does not submit your decision.
